# Harshi Mart – Online Shopping Application

## Project Overview
Harshi Mart is an online shopping application developed as a C++ capstone project. It provides a simple shopping interface where users can explore products, add items to a cart, and proceed to checkout. The project demonstrates the basic workflow of an e-commerce application.

## Features
- Product listing with prices and images
- Add-to-cart functionality
- Demo login and registration interface
- Checkout form
- Demo payment options
- Demo order confirmation

## Technologies Used
- **C++** – Backend server
- **HTML** – Web page structure
- **CSS** – Styling and layout
- **JavaScript** – Frontend interactions
- **SQLite** – Database support configured for the project

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Configure the project using CMake.
4. Build the project using the configured C++ compiler.
5. Run the application in your local environment.

## Important Note
This project currently demonstrates the shopping and checkout workflow. Login, registration, payment, and order confirmation are demo features; real payment processing and persistent order storage are not implemented.

## Project Purpose
The purpose of Harshi Mart is to understand the fundamentals of e-commerce application development, C++ backend programming, web technologies, and project structure.
